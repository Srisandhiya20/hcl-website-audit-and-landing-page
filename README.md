# hcl-website-audit-and-landing-page
Comprehensive website analysis and audit for HCL Technologies using Wappalyzer, GTmetrix, BrowserStack, and WIX. Includes landing page design, UI/UX recommendations, and SEO strategy.

Conducted a comprehensive website audit for HCL Technologies, focusing on digital marketing principles and UI/UX best practices.
Designed a targeted landing page for CloudSMART solutions to drive lead generation and brand visibility.
Identified key design and performance issues, offering actionable recommendations to improve responsiveness and user experience.
Proposed SEO and content structure enhancements to strengthen HCL’s online presence and engagement.
